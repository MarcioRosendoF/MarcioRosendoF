Game developer transitioning into backend development. I've built multiplayer systems (session management, reconnection flows)
and modular gameplay systems in Unity, from state-machine combat to UI systems.

Now I'm applying that same engineering mindset to Java, Spring Boot and REST APIs. The path started with a plain CRUD
and moved through security, event-driven messaging, caching and CI/CD, with each project building on the last.

---

## Projects

> Each repo is a step of my learning path, and every project adds a new layer of production complexity.

- [Task Manager API](https://github.com/MarcioRosendoF/task-manager-api): my first Spring Boot project, with layered architecture, DTOs and Bean Validation.
- [Purchase Verified Review API](https://github.com/MarcioRosendoF/purchase-verified-review-api): Spring Security + JWT, Flyway migrations, Testcontainers, CI pipeline.
- [Order Notification Service](https://github.com/MarcioRosendoF/order-notification-service): status transitions publish events to RabbitMQ; consumers turn them into notifications.
- [Booking Scheduler API](https://github.com/MarcioRosendoF/booking-scheduler-api): Keycloak OAuth2, Redis cache, async notifications, live on Railway 🌐
